# Left Thumbstick Zoom
Left Thumbstick Zoom is a mod for a niche game called VTOL VR that provides essential quality-of-life features to the game.
Honestly I just grew frustrated of the lack of this feature, so I went "fine, I'll do it myself.
## Tools used
- dnSpy was used to decompile the game's code.
- Harmony was used to directly patch my own code into the game's.
- This mod utilizes a community modloader built by Marsh.
